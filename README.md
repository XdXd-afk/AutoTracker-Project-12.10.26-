# Учёт обслуживания автомобиля (Бортовой журнал)

## Описание проекта
Десктопное приложение для автовладельцев, позволяющее вести учет выполненных работ, контролировать расходы, следить за текущим пробегом транспортного средства и прикреплять чеки или фотографии к записям. Программа разработана на языке Python с использованием графического фреймворка PySide6 и базы данных SQLite.

## Технологии
* **Язык программирования:** Python 3.14.7
* **Интерфейс:** PySide6 (Qt)
* **База данных:** SQLite3 (две связанные таблицы: `service_types` и `maintenance_records`)
* **Мультимедиа:** Отображение логотипов и привязка файлов чеков/фотографий (`QPixmap`)

## Функционал
* Просмотр истории обслуживания в виде удобной таблицы (`QTableWidget`).
* Добавление новых записей через отдельное диалоговое окно со списком категорий работ.
* Автоматический расчет общей статистики (суммарные затраты, общий пробег, количество записей).
* Поддержка горячих клавиш (`Ctrl + N` — добавление, `Delete` — удаление записи) и управления с помощью мыши.
* Использование стандартных диалоговых окон (`QMessageBox`, `QFileDialog`).
